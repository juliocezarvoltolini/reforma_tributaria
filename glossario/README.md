# /glossario/ — camada 2, curado à mão

`vocabulario.yaml` mapeia o vocabulário antigo (PIS, COFINS, ICMS, ISS) para o
novo (CBS, IBS, IS), além de siglas e termos cujo sentido técnico difere do
coloquial.

Toda equivalência exige `fundamento` (URN). Sem norma ingerida, fica
`pendente_fundamentacao: true` e serve **apenas para navegação** — nunca como
afirmação citável.
